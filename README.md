# Summit & Co. Events — Corporate Event Planning & Conference Management Website Template

**Summit & Co. Events** (*"Precision Behind Every Remarkable Event."*) is a luxury, corporate-grade HTML5 website template suite built for corporate event planners, conference management agencies, venue sourcing firms, and event production companies.

---

## 🌟 Key Features

- **16 Complete HTML Pages**:
  - `index.html` — Homepage 1 (Flagship Corporate Event Management Firm Overview)
  - `home-2.html` — Homepage 2 (Technical Conference Production & Large-Scale Operations)
  - `services.html` — Comprehensive 6-Pillar Services Index
  - `service-details.html` — Deep-Dive Service Blueprint (Full Planning, AV, Venues)
  - `events.html` — Event Archives Database (Conferences, Galas, Launches, Awards)
  - `event-details.html` — Premium Case Study Page (Strategy, Timeline, Outcomes)
  - `portfolio.html` — Interactive Portfolio Gallery (Category filter tabs + Lightbox modal)
  - `about.html` — Company Profile, Executive Team, Operational Standards & Sustainability
  - `insights.html` — Industry Blog & Strategy Insights
  - `blog-details.html` — Editorial Strategy Article Template
  - `contact.html` — Contact Headquarters & 11-Field Consultation Request Form
  - `login.html` — Standalone Client Portal Login (No Dashboard redirect)
  - `signup.html` — Standalone Company Registration (No Dashboard redirect)
  - `forgot-password.html` — Standalone Password Recovery
  - `404.html` — Event-Themed Custom 404 Error Screen
  - `coming-soon.html` — Live Countdown Teaser Page
- **Light & Dark Theme Engine**: Built-in toggle button with seamless `localStorage` persistence and automatic system preference detection.
- **Mandatory Navbar & Offcanvas Mobile Navigation**: Fully accessible responsive header with dropdown menus (`Home ▾`, `Services ▾`, `Events ▾`), touch-friendly targets, and body scroll lock.
- **Interactive JavaScript Features**:
  - Filterable portfolio gallery
  - Modal photo lightbox
  - Animated statistics counter numbers
  - Form validation logic with real-time feedback
  - Live countdown timer for upcoming summits
  - Back-to-top floating button
- **Responsive & Accessible**: Tested across all mobile, tablet, and desktop breakpoints (320px to 2560px+).

## 🚀 Quick Start & Customization

1. Open `index.html` in any web browser to view the site live.
2. Edit color tokens and typography in `assets/css/style.css` via CSS custom variables (`--accent-gold`, `--bg-primary`, `--text-primary`).
3. View complete customization instructions in `documentation/index.html`.
