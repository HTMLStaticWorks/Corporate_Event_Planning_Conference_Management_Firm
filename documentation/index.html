2. Light / Dark Theme Customization

All theme colors are declared as standard CSS variables in assets/css/style.css. To adjust the primary gold accent or background tones, update:

:root {
  --accent-gold: #C5A059;
  --bg-primary: #FAF9F5;
  --text-primary: #0F172A;
}

[data-theme="dark"] {
  --accent-gold: #D4AF37;
  --bg-primary: #0B0F17;
  --text-primary: #F8FAFC;
}

3. Interactive Features

  • Theme Switching: Handled in main.js via localStorage persistence.
  • Portfolio Filtering: Uses data-filter attributes on buttons and data-category on gallery items.
  • Modal Lightbox: Triggered via Bootstrap modal attributes with automatic image src replacement.
  • Form Validation: Standard HTML5 validation enhanced with needs-validation class and success alert toggling.
